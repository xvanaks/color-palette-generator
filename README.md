# Palette Generator

Минималистичный генератор эстетичных цветовых палитр в духе Coolors. Работает прямо в браузере без сборщиков и зависимостей.

## Возможности

- **Генерация по пробелу** — мгновенный подбор гармоничных оттенков.
- **Фиксация цветов (Lock)** — зафиксируй те цвета, что понравились, а остальные подберутся автоматически под них.
- **Свои цвета** — редактирование HEX прямо в строке или через палитру с пипеткой.
- **Гармонии** — автоподбор, аналоговая, контрастная, триада, монохром, пастель, яркая, темная, теплая, холодная.
- **Оттенки** — 10 уровней яркости для любого цвета в один клик.
- **Лайки и Избранное** — сохранение понравившихся палитр в память браузера.
- **Drag & Drop** — перетаскивание колонок мышкой для настройки порядка.
- **Макет UI** — интерактивный предпросмотр того, как палитра смотрится на реальном сайте.
- **Экспорт** — CSS переменные, конфиг Tailwind, список HEX, JSON и скачивание карточки в PNG.
- **Горячие клавиши** — `Пробел` (генерация), `Ctrl + Z` (назад), `Ctrl + Y` (вперед), `Esc` (закрыть окна).

## Быстрый старт

Откройте файл `index.html` в любом современном браузере.

## Стек

- Чистый HTML5
- Современный CSS3 (переменные, flexbox, glassmorphism)
- Vanilla JavaScript (алгоритмы цвета HSL/RGB, WCAG контраст)
